SICAS Control Panel

Environment checks

Everything the project needs on this machine. A red dot means a run that depends on it will fail; amber means optional. Use the buttons to fix items in one click.

    Anthropic API key optional

    Only needed to run with anthropic:<model> instead of the local Ollama model. Held in memory by this panel only (never written to disk) and cleared when you close it.

    Before any long run

    • Plug the laptop in and set Sleep: never (Settings → System → Power). A sleeping PC silently pauses the run.
    • Close heavy apps. Local inference uses all CPU cores; a 15 GB RAM machine should stay under ~70% memory use.
    • Only one run at a time is allowed from this panel. Stopping a run is safe; finished generations are already saved in runs/<name>/archive.
